Security
========

What shirudo protects, against whom, by which mechanism, and where each
mechanism stops. Start with the security model for the short version.
The threat model states every assumption, threat, residual risk and gap
not closed yet, with the hooks, counters and tests behind each claim.
The cryptography, tamper counter and integrity counter pages are
references, and the last page says how to report a vulnerability.
