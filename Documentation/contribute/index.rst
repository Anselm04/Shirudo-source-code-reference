Contribute
==========

These pages are for developers who change shirudo itself: its code, its
tests, its build and this documentation. Start with
:doc:`/contribute/code/developer-guide` to build from a clone, then
:doc:`/contribute/code/develop-locally` to run the operator and a target
on one machine and take a package through its life, and
:doc:`/contribute/testing/testing` to run the tests in the test VM that
plays a target. :doc:`/contribute/testing/test-coverage` shows what the
tests cover and what they do not. Before you send a change, read
:doc:`/contribute/code/contributing` and
:doc:`/contribute/code/coding-style`, and read
:doc:`/security/threat-model` first when the change touches a
security-relevant path. :doc:`/contribute/support` lists where to ask
questions and report problems.

- :doc:`code/index`: work from a checkout, develop locally, the coding
  style, and commits and sign-off
- :doc:`testing/index`: run and write tests, and test coverage
- :doc:`documentation/index`: writing docs and the logos
- :doc:`arch-support`: the state of x86-64, arm64 and riscv64, and the
  open work on each
- :doc:`support`: where to ask questions and report problems
